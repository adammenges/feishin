# Commits

Use Conventional Commits: `type(scope): subject`. Prefer a concise imperative subject and explain the reason and relevant validation in the body when needed. Do not add agent attribution.

Types: `feat`, `fix`, `perf`, `refactor`, `docs`, `style`, `test`, `build`, `ci`, `chore`, `revert`.

Optional scopes describe the product area: `player`, `radio`, `lyrics`, `library`, `servers`, `remote`, `theme`, `ui`, `visualizer`, `window`, `sharing`, `tag-editor`, `api`, `i18n`, `ci`, `deps`, `release`.

Stage and commit only when requested. Run the applicable native checks documented in `docs/native/README.md`. The retired JavaScript commitlint and staged-lint tooling is no longer part of the repository.
